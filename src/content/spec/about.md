# About 齊

這裡是 **齊（Chi）** 的個人網站。

我喜歡把自己正在做的事情整理下來，包含網站、程式、遊戲、裝置，以及一些值得留下來的紀錄。這個網站不追求一次完成，而是慢慢整理、持續更新，讓它成為一個能代表自己的地方。

## ✦ 現在

目前主要在維護自己的網站與幾個網路專案，也會持續研究自己感興趣的技術與工具。

平常會使用 **Astro、TypeScript、Svelte、Cloudflare、GitHub** 等工具，偶爾也會玩《崩壞：星穹鐵道》和《絕區零》。

## ✦ 這個網站

這個網站使用 **Astro 7、Svelte 5、TypeScript** 與 **Tailwind CSS 4** 建置，介面以 Material 3 Expressive 為基礎。

這裡會放一些我想留下來的東西，例如作品、裝置、遊戲與日常紀錄。沒有內容的地方就先留白，等真的有值得分享的東西，再慢慢補上。

## ✦ 關於我

我習慣先觀察、研究，再自己動手試。

很多事情不一定會在一開始就有完整答案，我比較喜歡先做出一個能運作的版本，再一點一點調整。對我來說，這個網站也是一個持續整理與實驗的空間。
