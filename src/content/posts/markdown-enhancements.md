這個網站對外使用 **Chi**。

中文則會使用 **齊**。

這兩個名字沒有什麼複雜的設定，就是希望網站上看到的身份簡單一點。

GitHub 帳號是 GitHub 帳號。

網站則是網站。

所以我在網站裡沒有特別想把帳號名稱放得到處都是。

## 為什麼是 Chi？

Chi 很短。

網址也短。

放在標題、頁尾、瀏覽器分頁上都不會太擁擠。

而且看起來不像一個需要解釋很久的品牌名稱。

我比較喜歡這種感覺。

不用很用力介紹自己。

看到 Chi，就知道這裡是我的小角落。

## 這個網站也是一種簽名

沒有很正式。

只是把名字放在自己做的東西旁邊。
