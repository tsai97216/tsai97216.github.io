我有一個習慣：只要某個東西真的做過一段時間，就會想把它留在 GitHub。

不一定代表它還在活躍開發。

有時候只是因為，以後回頭看會知道自己曾經走過哪條路。

## 網站

現在最明顯的一個就是這個網站。

它從主題模板開始，慢慢換成自己的名稱、文字、資料和文章。

我沒有打算一次把所有東西做完，因為網站本來就可以慢慢長大。

## 小工具與服務

另外一些專案則比較偏實用。

例如用 Cloudflare Worker 處理資料、GitHub Pages 放靜態網站，或者在 VPS 上跑 Docker 服務。

它們沒有什麼華麗的介面，但解決問題就已經有價值。

## 為什麼還要留著？

因為 GitHub 對我來說不只是程式碼倉庫。

它比較像一排時間膠囊。

過幾個月再打開以前的 commit，可能會發現以前覺得很麻煩的事情，現在已經知道怎麼處理了。

這種變化本身就值得留下來。
