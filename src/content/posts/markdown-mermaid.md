我其實沒有每天盯著伺服器。

大多數時候，它最理想的狀態就是沒有任何事情需要我處理。

但偶爾還是會連進去看一下。

## 我最常看的三件事

### 1. 系統有沒有正常運作

```bash
uptime
free -h
df -h
```

這三個指令很樸素，卻已經能回答很多問題：系統跑多久了、記憶體夠不夠、磁碟是不是快滿了。

### 2. Docker 有沒有正常

我的服務大多放在 Docker 裡，所以更新時通常也是同一套流程：

```bash
docker compose pull
docker compose up -d
```

不用每天碰它。真的需要更新時再處理就好。

### 3. 日誌有沒有出現奇怪的東西

如果某個服務突然不對，第一反應通常不是重灌，而是先看 log。

因為「不知道發生什麼事」通常比「真的壞掉」更麻煩。

## 我喜歡的伺服器狀態

不是跑滿所有資源，也不是塞滿一堆服務。

而是安靜地跑著，需要它的時候找得到，出問題時也看得懂。

對我來說，這就夠了。
